## Style
- Formal but clear; second person “tú” or impersonal “se” as in catechetical Spanish; prefer “usted”-level formality via impersonal constructions where English is instructional.
- Preserve markdown structure, frontmatter keys; translate title/tags values carefully.
- Preserve links paths (same relative URLs); translate link text.
- Translate admonition titles in body; plugin also has admonition_translations.
- For canonical prayers, use the standard Spanish liturgical text of the Catholic Church.
- Do not invent quotes; translate quoted English prose faithfully; for known magisterial docs prefer official Spanish when you know it, else careful translation marked by fidelity to the English on-site text.
- Keep book/author names in bibliographic lists; translate descriptive labels around them.
- Filename for Spanish: same path with `.es.md` suffix (e.g. `index.es.md`, `hypostatic-union.es.md`).
- If page uses `--8<-- "includes/study-prompts.md"`, Spanish page must use `--8<-- "includes/study-prompts.es.md"`.

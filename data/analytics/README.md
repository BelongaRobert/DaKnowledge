# Analytics snapshots

Weekly GitHub Action (`analytics-weekly.yml`) writes:

- `YYYY-Www.json` — full machine snapshot for that ISO week
- `latest.json` / `latest.md` — most recent report
- `index.json` — list of recorded weeks

Live counters (may reset on Render cold start): https://daknowledge-x402.onrender.com/metrics

See `api/ANALYTICS.md`.

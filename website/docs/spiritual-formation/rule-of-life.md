# A light rule of life

A rule is a fence, not a performance. Keep it small enough that you will still do it in a hard week.

---

## The whole rule

1. **Sunday:** Mass, and Holy Communion if you are in a state of grace.
2. **Daily:** the [Our Father](../prayer/lord's-prayer/), slowly, once.
3. **Weekly:** one doctrine page from a [study track](../study/tracks/), or the next page in the sidebar.
4. **When you can:** one decade of the Rosary, or [lectio](lectio/) on a single verse from that page.

That is all. If you add more, add it after this holds for a month.

---

## What not to do

Do not read the whole site. Do not start three tracks. Do not skip the sacrament for more articles.

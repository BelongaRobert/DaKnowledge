# Study

Use this site as a tool, not as a pile. Everything is still in the sidebar. You do not have to read it all.

**One page a sitting is enough.** Search if you need a name or a verse. Open a track if you want a path.

## How a page is meant to be used

Read the teaching. Look at the Scripture. If you want to linger, open **For study** at the bottom. It is the same four questions on every doctrine page. You can ignore it.

Then pray something small: the [Lord's Prayer](../prayer/lord's-prayer/), or a [lectio](../spiritual-formation/lectio/) on one verse from the page.

---

# Tres itinerarios

Elige **uno**. No los hagas a la vez.

Cada paso es una sesión: la página, luego las cuatro preguntas de estudio si las quieres, y luego parar.

---

## Inquiriente {#inquirer}

Para quien es nuevo, regresa o está en el RICA. Unas ocho sesiones.

1. [Existencia de Dios](../theology-proper/existence-of-god/)
2. [La Santísima Trinidad](../trinity/)
3. [Unión hipostática](../christology/hypostatic-union/)
4. [Sagrada Escritura](../scripture/)
5. [Bautismo](../sacraments/baptism/) y [Eucaristía](../sacraments/eucharist/)
6. [El Padre nuestro](../prayer/lord's-prayer/) y [el Ave María](../prayer/hail-mary/)
7. [Madre de Dios](../mariology/theotokos/)
8. [Cielo, Infierno y Purgatorio](../eschatology/last-things/)

Cuando una palabra resulte extraña, usa el [glosario](glossary/).

---

## Parroquial {#parish}

Para un grupo que se reúne semanalmente. Una página, veinte minutos de conversación. Usa la [hoja de diálogo](../spiritual-formation/discussion/).

| Semana | Página |
|--------|--------|
| 1 | [Teología propiamente dicha](../theology-proper/) |
| 2 | [La Santísima Trinidad](../trinity/) |
| 3 | [Persona de Cristo](../christology/person-of-christ/) |
| 4 | [Justificación](../soteriology/justification/) |
| 5 | [Naturaleza de la Iglesia](../ecclesiology/nature-of-the-church/) |
| 6 | [Eucaristía](../sacraments/eucharist/) |
| 7 | [Virtud y pecado](../moral-theology/virtue-and-sin/) |
| 8 | [Reflexión sobre el discipulado](../spiritual-formation/discipleship-reflection/) |

El líder lee la página de antemano. El grupo no necesita toda la barra lateral.

## Más profundo {#deeper}

Para quien ya conoce el esquema del catecismo y quiere las articulaciones.

1. [Trinidad económica e inmanente](../trinity/economic-immanent/)
2. [Dos naturalezas](../christology/two-natures/) y [Concilios](councils/)
3. [Interpretación bíblica](../scripture/interpretation/)
4. [Expiación](../soteriology/atonement/) y [Elección](../soteriology/election/)
5. [Ley y conciencia](../moral-theology/law-and-conscience/)
6. Un artículo sobre una reliquia como laboratorio, no como fe exigida: [Sábana Santa de Turín](../relics/shroud-of-turin/)
